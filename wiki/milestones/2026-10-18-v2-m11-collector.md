# v2 m11: event sink and collector

**Done when** (AGENTS.md): two local agents report into one collector.

`TestTwoAgentsReportToOneCollector` in `internal/central/central_test.go` does this: two data dirs
(hosts `laptop-a`, `laptop-b`) with audit logs that contain a fake secret in a summary and a reason
ship to one collector. `/v1/hosts` shows 3 and 2 events with the right verdict counts, `/v1/events`
returns all five, a second ship makes no request, and no `FakeSecrets` value is in a response or in
`events.jsonl`.

## Delivered

- [`internal/sink`, `internal/central`](../components/2026-10-18-sink-collector.md): the shipper
  (`sink.Ship`) and the collector (`central.Handler`, `central.Serve`).
- `mcpgraph sink set|off|status|flush`, `mcpgraph collector`, and `mcpgraph events --collector URL
  [--token] [--host]`, which reuses `report.Events` on the decisions the collector returns.
- The proxy ships after each recorded decision (one background flush at a time) and once more on
  exit. Design: [ship from the audit log](../decisions/2026-10-18-ship-from-audit-log.md).
- The old no-op `Sink` interface for snapshots was replaced, not kept next to the new code.
- Tests: sink off makes no request, bad token gives 401 and keeps the offset, a partial last line
  waits, 8 concurrent `Ship` calls send each event once, a retry after a 500 does not duplicate,
  dedup survives a collector restart, a 4 MiB+ body gets 413, `sink set/status/off` mask the token
  and write 0600.

## Notes

- Hook wiring is not here: the hook command (milestone 9, separate branch) should call
  `sink.NewFlusher(dir)` / `sink.Ship(ctx, dir)` after it records a decision.
- The collector keeps all events in memory (loaded from `events.jsonl` at startup). Fine for a small
  self-hosted collector; a database is future work.
- `sink set` warns on stderr for plain `http://` to a non-loopback host (the R7 posture).
- `sink off` keeps `sink.offset`, so turning the sink on again does not re-send old history.

## Go concepts

- **`syscall.Flock` with `LOCK_NB`**: a cross-process lock on a file, non-blocking, released when the
  file is closed or the process dies. Several proxies can try to ship; one wins, others skip.
- **Embedding for JSON**: `Event` embeds `model.Decision`, so `encoding/json` flattens the fields
  next to `id`; `Stored` embeds `Event` again.
- **`atomic.Bool` + `sync.WaitGroup`**: `CompareAndSwap` gives "at most one flush at a time" without a
  mutex; the WaitGroup lets `Close` wait for it.
- **`http.MaxBytesReader` + `errors.As(*http.MaxBytesError)`**: cap the body and turn the typed error
  into a 413.
- **`http.Server.Shutdown` with a fresh context**: the request context is already cancelled, so
  graceful shutdown needs a new deadline. Go 1.22 `ServeMux` patterns (`"POST /v1/events"`) route by method.
