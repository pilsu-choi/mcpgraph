# v2 m10: DROP TABLE demo

**Done when** (AGENTS.md): `make demo` runs end to end on a clean machine and shows both paths
blocking `DROP TABLE`; the README opens with a ~30 second animation of it (owner decision: an
animated SVG made by `tools/termsvg`, not a GIF).

## Delivered

- `demo/docker-compose.yml` and `demo/seed.sql`: `postgres:17.6-alpine`, bound to `127.0.0.1` only
  on port 55442 (`DEMO_PG_PORT` overrides it; 55432 is often taken), fake demo-only credentials,
  a healthcheck, and fake `users` and `orders` rows.
- `demo/proxy-demo.sh` (path A): a client session through `mcpgraph proxy` to the real
  `@modelcontextprotocol/server-postgres@0.6.2`. `SELECT count(*)` is answered, `DROP TABLE users`
  gets an `isError` result naming `block-destructive-sql`, then `mcpgraph events` and a `psql`
  inside the container prove the table survived. Verified for real.
- `demo/hook-demo.sh` (path B): throwaway project with a project-local `.claude/settings.json`
  (PreToolUse, matcher `Bash`, `onFailure: block`), a `psql` wrapper on `PATH`, one `claude -p` run,
  then `mcpgraph events --verdict deny` and the same proof. It stops with a clear message while
  `mcpgraph hook claude-code` is still a stub.
- `demo/run.sh` (`make demo`): builds mcpgraph into a temp dir, runs both paths, and tears the
  database down with `docker compose down -v` from an `EXIT` trap. `make demo-down` cleans up after
  an interrupted run. `SKIP_HOOK=1` runs only path A.
- `tools/termsvg -animate`: timed transcripts to a looping SVG (CSS keyframes only). Static mode is
  unchanged and shares the document code. Tests cover XML validity, line count, keyframes and escaping.
- `demo/record.sh`: records the proxy path and builds `docs/images/demo-draft.svg` (placeholder hook
  lines, clearly marked); `--final` with `HOOK_TRANSCRIPT=` writes `docs/images/demo.svg`.

## Notes

- `@modelcontextprotocol/server-postgres` is **deprecated on npm** ("no longer supported") but 0.6.2
  still runs and is read-only, which suits the demo: mcpgraph blocks the DROP before the server sees
  it. It is pinned (also avoids posture rule R3). It answers `protocolVersion` 2024-11-05.
- Its answers put `result` before `jsonrpc`, so the script matches `"id":N` instead of a fixed key order.
- A first version of the stub check used `cmd | grep -q`; with `pipefail` the early-closing `grep`
  made the pipeline fail, the check was skipped, and `claude` ran against the stub. The hook failed
  and `onFailure: block` stopped every command, which also showed that setting works. Fixed by
  capturing the output first.
- The animation was checked as XML only; no browser was available to look at it.

## Go concepts

- **Shared renderer with a callback.** `document` takes an `attrs func(i int) string`, so static and
  animated output share one layout without a flag soup.
- **`strings.CutPrefix`** parses the `#@ seconds` directives without index arithmetic.
- **Table-free XML check.** `encoding/xml`'s `Decoder.Token` loop fails on any bad escaping, a cheap
  validity test for generated markup.
- **`errors.Is(err, io.EOF)`** ends the token loop; any other error is a real failure.
- **`go build -o dir/`** builds a binary into a temp directory, which keeps demo runs out of the repo.
