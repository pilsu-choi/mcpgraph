# v2 m8: install and uninstall

**Done when** (AGENTS.md): `install` then `uninstall` restores every file byte for byte, and posture
rule R4 ("not proxied") clears after install.

- `TestRoundTrip` in `internal/install/install_test.go` uses a fixture home. R4 is 6 findings before,
  0 after install and 6 after uninstall. All four config files are byte-identical with the same mode
  after uninstall.
- `TestInstallCommandRoundTrip` in `cmd/mcpgraph/install_test.go` does the same through the CLI.

## Delivered

- [`internal/install`](../components/2026-10-18-install.md) and
  `mcpgraph install [--app] [--server] [--policy] [--bin] [--yes]` / `mcpgraph uninstall [--yes]`.
- Every stdio server becomes
  `<abs mcpgraph> proxy --server NAME --app APP [--data-dir D] [--policy P] -- <orig cmd> <orig args>`.
  Remote (http/sse) servers and already-proxied ones are listed as "left alone".
- Without `--yes` it is a dry run: it prints the plan and a diff and writes nothing.
- [Edit in place, not re-serialize](../decisions/2026-10-18-install-in-place-edits.md): only the
  `command` and `args` values change, so comments, indentation and key order survive.
- Backups (mode 0600 in a 0700 directory, never overwritten) and a manifest with hashes and offsets
  only, so the manifest cannot leak a secret.
- Atomic writes that refuse to run over a file the app changed meanwhile. Symlinked configs keep
  their link (`TestSymlinkedConfig`).
- Uninstall in three modes: `restore`, `unwrap` and `gone`.
- Hard rule 2 in the diff: a JSON-aware line redactor ([lesson](../lessons/2026-10-18-json-diff-redaction.md)).
  `TestNoSecretInOutputOrManifest` checks the diffs and the manifest.
- `install` refuses a binary path from `go run` (it contains `go-build`) or a binary not named
  `mcpgraph`, because scans recognise proxied servers by that basename; it asks for `--bin`.
- Less duplicate code: `config.StripJSONC` and `config.MaxConfigSize` were exported and reused, and
  `config.UnwrapProxyCommand` is shared by the scan (proxied detection), install (skip already-proxied)
  and uninstall (unwrap).

Code commit: `05cdf7c` (branch `m8-install`, to be merged to `dev`).

## Go concepts

- **`os.Rename` is atomic inside one directory.** Write a temp file next to the target, `Sync` it,
  `chmod` it to the original mode, then rename over the target.
- **`os.OpenFile` with `O_CREATE|O_EXCL`** fails if the file exists, so a backup is never overwritten.
  `os.MkdirTemp` makes a unique directory. `filepath.EvalSymlinks` finds the real file behind a symlink.
- **`crypto/sha256` and `encoding/hex`** give the hashes that detect "the app changed the file".
- **A recursive-descent parser that records byte offsets** (max depth 512) lets code change two values
  and leave the rest of the bytes alone. `sort.Search` finds the line of an offset in the sorted
  list of line starts.
- **`json.Encoder.SetEscapeHTML(false)`** keeps `<`, `>` and `&` readable in the command lines written back.
