# `internal/hook`

| File | Role |
| --- | --- |
| `hook.go` | `Adapter` (`ClaudeCode`, `Codex`), `Lookup`, `Parse` (payload -> `policy.Action`), `Encode` (Decision -> stdout bytes). |
| `config.go` | `ConfigSnippet`: the JSON for `~/.claude/settings.json` or `~/.codex/hooks.json`. Builds text only. |

`cmd/mcpgraph/hook.go` is the glue: `buildEngine` -> `Parse` -> `policy.Judge` -> audit -> `Encode`.

Rules of the adapter:

- `Action{Source: hook, Agent, App, Tool: tool_name, Args: tool_input, Cwd}`. MCP tools keep the full
  `mcp__server__tool` name.
- `Text` is `tool_input.command` (Bash, Codex `apply_patch`) or `tool_input.file_path` (Read/Edit/
  Write); empty for MCP tools, so the engine inspects all their string arguments.
- Allow encodes to nothing, so the agent's own prompt still applies. Unknown verdicts become a deny.
- Ask is native for Claude Code and a deny with an approval hint for Codex.
- Errors never contain payload text. The unknown_tool rule is proxy-only (`KnownTool` is nil).
