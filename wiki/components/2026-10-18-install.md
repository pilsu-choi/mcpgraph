# `internal/install`

| File | Role |
| --- | --- |
| `jsonscan.go` | Span-preserving JSON/JSONC parser: each value keeps its byte range; handles comments and trailing commas; max depth 512. |
| `locate.go` | Finds server entries per app (same shapes as the [config collector](config-collector.md)) and tells whether one is already proxied. |
| `edit.go` | `Edit` (replace a byte range), `applyEdits`, `reverseEdits`, and `rewrite`, which sets `command` and `args` (inserting `args` after `command` if missing). |
| `diff.go` | Unified-style diff built straight from the edits, and `redactJSONLine`. |
| `plan.go` | `Options`, `Plan` (read configs, work out edits, write nothing), `readConfig` (symlinks, size limit). |
| `apply.go` | `Apply`: back up, write atomically, record in the manifest. |
| `manifest.go` | `Manifest` and `Record` (paths, hashes, edit offsets, never contents) and `writeAtomic`. |
| `uninstall.go` | `PlanUninstall` and `ApplyUninstall`: restore, unwrap or gone. |

## Flow

- **install.** `Plan` resolves symlinks, reads each config and finds its server entries. stdio
  entries get edits; http/sse and already-proxied entries become skips. The diff comes from the edits.
  Without `--yes` the command stops here. With it, `Apply` copies each file to a backup (`O_EXCL`),
  then `writeAtomic` writes a temp file, syncs it, restores the mode, checks the target's sha256 still
  matches what was read, and renames. The record goes into the manifest straight after each file.
- **uninstall.** `PlanUninstall` takes the records newest first and compares each file's sha256 with the
  recorded "after" hash. Equal: `restore`, the backup is written back byte for byte. Different: `unwrap`,
  the proxy wrapping is removed in place with `config.UnwrapProxyCommand`. File missing: `gone`.
  Several records for one file are chained in memory and the file is written once. Backups are
  deleted after a restore.

## Choices

- [Edit in place and restore-vs-unwrap](../decisions/2026-10-18-install-in-place-edits.md).
- Backups hold the only copy of original bytes; the manifest is safe to print.
- A `changed while mcpgraph was working on it` error beats losing the app's own write.
